# 实施契约（本地 Demo／测试版）

## 范围与边界

本工程是本地排产 Demo／测试版，用于生产部署前的本地验证，不读取真实订单或内部配置、不调用生产 MES。仅使用原创合成订单、工艺与库存。用户已批准逐个实现和私有发布，发布前必须独立验收与内容审查。

## 分层

1. 严格整数数量、整数分钟的订单/整批工序/物料/资源/日历与冻结快照。
2. 受控情景变更编译为不可变问题，OR-Tools CP-SAT 实际求解。
3. 独立验证器重新计算数量、工序、资源、日历、换型、物料、冻结与目标；微型枚举 oracle 独立核对。
4. 单 Agent ReAct 选择受控取证、情景、编译、求解、独验、比较、补问、送审工具；模型文字不能成为排程，也不能豁免约束。
5. 图外人工审阅、签名发布、本地隔离接收端的部分/完整接收、独立状态核验和合成执行分别记账。
6. 原创离散事件执行引擎实际推进订单与资源事件；插单、停机和供料延迟只在合成情景验证。

## 安全运行

- 本地身份由服务端鉴权，owner + plant 隔离，角色不来自请求体；admin 不自动获得其他 owner 对象。独立人工动作不是默认强制双人复核。
- 工具参数与状态严格匹配，快照版本/内容 hash、编译版本、候选和独验结果必须绑定；禁止跨任务借证据。
- 请求幂等、乐观版本、事务、租约、模型调用日志、累计预算、取消和未知结果对账不能以测试 stub 替代。
- 模型请求只允许显式数字回环 HTTP，不走代理、重定向、外部追踪或云端后备；TEST provider 必须明确标识。
- 真实推理、TEST 编排、CP-SAT 求解、独验、Chrome、安装与合成执行分开验收。
- SQLite/单机签名接收器不是分布式 exactly-once 或物理现场执行；未知响应不得盲目重发。
- 库存签名和证据哈希语义不同：普通内容哈希不是身份签名。发布认证必须使用持有本地秘密的 HMAC，秘密留在仓库外。

## 工程与发布

Python 3.12，uv 锁依赖，FastAPI/Pydantic，LangGraph，OR-Tools CP-SAT，原生中文浏览器工作台。所有模块必须独立安装，不依赖其他参考仓库的运行时路径。

提交范围仅原创源码、合成生成器、测试、文档、锁文件；模型、数据库、凭据、运行配置、浏览器 profile、原始验收数据与依赖 wheelhouse 不上传。不擅自添加整体开源许可，不启用 Pages、不部署、不覆盖同名远端、不强推。

最终验收包括完整一次 pytest、Ruff/JS/锁、正常/无解/缺失及扰动场景、实际本地模型与 Chrome、源码外 fresh venv 离线安装、候选/暂存/全部提交和逐远端 blob 核对。未通过项不记成功，不相加局部测试数。
